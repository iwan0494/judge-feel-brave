A small Python program for make.fun's "Make the AI judge feel brave"
bounty: it writes one short text to `/output/entry.txt`, a text written
to relax the AI judge reading it. The program uses only the standard
library, needs no network, and always writes the same text.

## Run it

```sh
python3 main.py
```

That writes the entry text to `/output/entry.txt`.
